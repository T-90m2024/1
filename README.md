# Random Task Generator

**Автор:** Чижов Юрий
**Дата** 04.05.2026

## Описание

«Random Task Generator» — это графическое приложение на Python для генерации случайных задач. Приложение помогает разнообразить повседневные дела, случайным образом выбирая задачу из заданного списка. Подходит для использования в личной продуктивности, учёбе или в качественного инструмента для команды.

## Функциональность

- ✅ **Генерация случайной задачи** — нажатие кнопки выбирает случайную задачу из предопределённого списка и пользовательских задач
- ✅ **История задач** — все сгенерированные задачи сохраняются с временной меткой
- ✅ **Добавление своих задач** — возможность добавлять новые задачи с указанием типа (учёба, спорт, работа)
- ✅ **Фильтрация по типу** — просмотр истории только задач определённого типа
- ✅ **Сохранение данных** — автоматическое сохранение истории и пользовательских задач в JSON-файл
- ✅ **Валидация ввода** — проверка на пустые строки и дубликаты задач
- ✅ **Очистка истории** — возможность полностью очистить историю задач

## Технологии

- Python 3.x
- Tkinter (графический интерфейс)
- JSON (хранение данных)
- Random (генерация случайных задач)

## Установка и запуск

### Требования
- Установленный Python 3.6 или выше
- Стандартная библиотека Python (дополнительных установок не требуется)

### Запуск приложения

Примеры использования

Пример 1: Генерация задачи

1 Запустите приложение

2 Нажмите кнопку «Сгенерировать задачу»

3 Внизу появится случайная задача (например, «Прочитать статью по Python (учёба)»)

4 Задача добавится в историю с временной меткой

Пример 2: Добавление своей задачи

1 В поле «Название задачи» введите «Выучить английские слова»

 2 Выберите тип «учёба»

 3 Нажмите «Добавить задачу»

 4  Теперь эта задача будет доступна для случайной генерации

Пример 3: Фильтрация истории

1 Сгенерируйте несколько задач разных типов

2 В выпадающем списке фильтра выберите «спорт»

3 В истории останутся только задачи со спортивной тематикой

Пример 4: Очистка истории

1 Нажмите кнопку «Очистить историю»

2 Подтвердите действие

3 История будет полностью удалена, но предопределённые и пользовательские задачи сохранятся
